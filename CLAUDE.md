# CLAUDE.md

## About this repo

This repository is a scratchpad for various explorations: experiments, prototypes,
spikes, and one-off investigations. Projects here are independent of one another
and are not expected to share code, dependencies, or tooling.

## Rules

- **Every piece of scratchpad work must live in its own folder** at the repo root
  (for example, `my-exploration/`). Do not put project files at the repo root.
- Keep each folder self-contained: its own dependencies, config, scripts, and
  notes. Don't reach into or modify another exploration's folder unless asked.
- Use a short, descriptive, kebab-case folder name for each new exploration.
- Add a brief `README.md` inside each folder explaining what it explores and how
  to run it.
- Only shared, repo-wide files (like this `CLAUDE.md` or a root `.gitignore`)
  belong at the root.
